# Findings (Phase 1)

Generated by `python -m pricing_crosscheck run --profile full` from `results/full`. Each finding states what was observed and the experiment that supports the stated cause. None of them is a claim about QuantLib source code; they describe the behaviour of the Python wheel (QuantLib 1.43) at the settings in the protocol.

## 1. QuantLib LR tree: even step counts

Observed: with an even number of steps `BinomialLRVanillaEngine` converges at first order, with errors several orders of magnitude above the neighbouring odd counts. The protocol setting (1001 steps) is odd. Experiment `lr_even_odd` (European call, call|K=100|D=365|v=0.3|r=0.05|q=0.03):

| steps | abs error |
|---|---|
| 50 | 0.2439 |
| 51 | 2.14e-04 |
| 100 | 0.1233 |
| 101 | 5.55e-05 |
| 200 | 0.06198 |
| 201 | 1.41e-05 |
| 400 | 0.03108 |
| 401 | 3.56e-06 |
| 800 | 0.01557 |
| 801 | 8.94e-07 |
| 1600 | 0.007791 |
| 1601 | 2.24e-07 |

Likely cause: the Leisen-Reimer construction is defined for odd step counts; consistent with the even-count tree not being centred on the strike. See `docs/figures/lr_even_odd.png`.

## 2. QuantLib FD theta behaves like a one-day difference

Observed: FD theta does not converge to the analytic theta when the time grid is refined (`fd_theta_vs_tgrid`). It agrees with a one-sided closed-form difference over 0.99 days, (V(T - h) - V(T)) / h with h = min(0.99/365, 0.99 T), up to grid error. The step h = 0.99 days was chosen after seeing the FD values (a one-day step agrees less well), so the agreement identifies the step rather than testing an independent prediction:

| maturity | QuantLib FD theta (1600 x 1600) | closed-form 0.99-day difference | difference |
|---|---|---|---|
| D=1 | -208.9 | -208.8 | -0.1008 |
| D=7 | -45.76 | -45.76 | -7.71e-05 |
| D=365 | -6.192 | -6.192 | -1.95e-05 |

Consequence: near expiry the FD theta differs strongly from the instantaneous theta (see the Greeks table in `results/full/summary.md`). This is a definitional difference (finite time step) rather than a grid-convergence problem.

## 7. American calls without dividends at negative rates

Observation: with r < 0 and q = 0 the reference shows an early-exercise premium over the European call at 91 of 134 points (premium above 1e-3), largest 17.29. The no-early-exercise argument requires r >= 0, so this is expected.
